# Data dictionary: `steam_clean.sqlite`

Generated by `notebooks/01_data_cleaning_and_setup.ipynb` (Section 12). Scrape date: 2025-09-29. Prices are US dollars.

## games

| Column | Type | Description |
|---|---|---|
| `appid` | INTEGER | Steam application ID. Primary key. |
| `name` | TEXT | Store listing name. Not unique; appid is the entity key. |
| `is_free` | INTEGER | 1 if the listing is free to play, else 0. Free games have NULL prices. |
| `release_date` | TEXT | ISO date (YYYY-MM-DD). NULL when missing, out of range (before 1990 or after the scrape date) or unreleased. |
| `release_year` | INTEGER | Year of release_date. NULL where release_date is NULL. 2025 is a partial year (to 2025-09-29). |
| `required_age` | INTEGER | Steam age gate (0 for 99.1% of games). Weak analytical variable. |
| `short_description` | TEXT | Store-page blurb. |
| `supported_languages` | TEXT | Raw supported-language string from the store page (not parsed). |
| `metacritic_score` | INTEGER | Metacritic score 0-100. NULL for 97.2% of games. |
| `recommendations_total` | INTEGER | Total recommendations. NULL means not reported (reported only above about 100). |
| `discount_percent` | INTEGER | Discount active at scrape time (2025-09-29), a snapshot, not a history. NULL where the listing has no price. |
| `currency` | TEXT | Original listing currency (33 codes). price_usd is populated only where currency is USD: 88,943 of 90,311 priced games. The 1,368 non-USD listings keep their currency but have NULL prices. |
| `achievement_count` | INTEGER | Number of achievements. NULL where not reported. |
| `price_usd` | REAL | Initial price in US dollars (source cents / 100). USD listings only; NULL for free or non-USD. |
| `price_final_usd` | REAL | Price after discount in US dollars. Same coverage as price_usd. |
| `is_unreleased` | INTEGER | 1 if the raw release date was after the scrape date (release_date is then NULL). |
| `has_relational_metadata` | INTEGER | 0 only if the game has no genre, category, developer or publisher rows. |
| `pc_os_min` | TEXT | Minimum PC requirements, OS (raw text). |
| `pc_processor_min` | TEXT | Minimum PC requirements, processor (raw text). |
| `pc_memory_min` | TEXT | Minimum PC requirements, memory (raw text). |
| `pc_graphics_min` | TEXT | Minimum PC requirements, graphics (raw text). |
| `pc_os_rec` | TEXT | Recommended PC requirements, OS (raw text). |
| `pc_processor_rec` | TEXT | Recommended PC requirements, processor (raw text). |
| `pc_memory_rec` | TEXT | Recommended PC requirements, memory (raw text). |
| `pc_graphics_rec` | TEXT | Recommended PC requirements, graphics (raw text). |

## genres

| Column | Type | Description |
|---|---|---|
| `genre_id` | INTEGER | Surrogate ID (alphabetical). Primary key. |
| `genre_name` | TEXT | Canonical English genre; 154 raw translated IDs consolidated. |

## categories

| Column | Type | Description |
|---|---|---|
| `category_id` | INTEGER | Source category ID. Primary key. |
| `category_name` | TEXT | English store category (non-English entries removed). |

## developers

| Column | Type | Description |
|---|---|---|
| `developer_id` | INTEGER | Canonical developer ID. Primary key. |
| `developer_name` | TEXT | Developer name; IDs sharing a trimmed, lowercased name were merged. |

## publishers

| Column | Type | Description |
|---|---|---|
| `publisher_id` | INTEGER | Canonical publisher ID. Primary key. |
| `publisher_name` | TEXT | Publisher name; merged the same way as developers. |

## platforms

| Column | Type | Description |
|---|---|---|
| `platform_id` | INTEGER | 1 = windows, 2 = mac, 3 = linux. Primary key. |
| `platform_name` | TEXT | Platform name. |

## game_genres

Junction table; primary key is (appid, id column). One row per game-attribute pair.

| Column | Type | Description |
|---|---|---|
| `appid` | INTEGER | FK to games. |
| `genre_id` | INTEGER | FK to genres. |

## game_categories

Junction table; primary key is (appid, id column). One row per game-attribute pair.

| Column | Type | Description |
|---|---|---|
| `appid` | INTEGER | FK to games. |
| `category_id` | INTEGER | FK to categories. |

## game_developers

Junction table; primary key is (appid, id column). One row per game-attribute pair.

| Column | Type | Description |
|---|---|---|
| `appid` | INTEGER | FK to games. |
| `developer_id` | INTEGER | FK to developers. |

## game_publishers

Junction table; primary key is (appid, id column). One row per game-attribute pair.

| Column | Type | Description |
|---|---|---|
| `appid` | INTEGER | FK to games. |
| `publisher_id` | INTEGER | FK to publishers. |

## game_platforms

Junction table; primary key is (appid, id column). One row per game-attribute pair.

| Column | Type | Description |
|---|---|---|
| `appid` | INTEGER | FK to games. Source of truth for platform support. |
| `platform_id` | INTEGER | FK to platforms. |
